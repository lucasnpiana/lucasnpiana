## 🚀 Projetos em Destaque

### [task-api](https://github.com/lucasnpiana/task-api)
API REST serverless para gerenciamento de tarefas desenvolvida com AWS Lambda, Prisma ORM e Neon (PostgreSQL).
`TypeScript` `AWS Lambda` `Prisma` `PostgreSQL`

### [job-finder-node](https://github.com/lucasnpiana/job-finder-node)
Aplicação web para busca e publicação de vagas de tecnologia, construída com Node.js, Express e banco de dados relacional.
`JavaScript` `Node.js` `Express` `SQL`

### [animatch-anilist](https://github.com/lucasnpiana/animatch-anilist)
Extensão de navegador para descoberta de animes usando recomendações do AniList, com filtros de gênero/duração e fila personalizada.
`JavaScript` `HTML5` `CSS3` `REST/GraphQL API`

### [simulador-bios-uefi](https://github.com/lucasnpiana/simulador-bios-uefi)
Simulador interativo de firmware BIOS/UEFI no navegador explorando configurações de sistema, ordem de boot e interfaces de hardware.
`JavaScript` `HTML5` `CSS3`

### [devhouse](https://github.com/lucasnpiana/devhouse)
Aplicação/backend para reserva de imóveis e espaços estruturada com cadastro de anúncios, reservas e usuários.
`JavaScript` `Node.js` `Express`
